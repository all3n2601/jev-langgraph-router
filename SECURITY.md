# Security policy

## Supported versions

No public version is supported yet. This repository is pre-alpha.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Once the repository is hosted, use the
host's private security-advisory feature. Until then, contact the repository owner privately.

Include affected versions, impact, reproduction steps, and any suggested mitigation. Maintainers
should acknowledge a report within five business days and provide a status update within ten.

Never include real credentials, customer data, or sensitive graph state in a report. Use synthetic
fixtures and revoke any credential that may have been exposed.
