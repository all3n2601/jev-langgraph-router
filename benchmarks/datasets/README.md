# Dataset registry

Each dataset receives its own directory and dataset card containing origin, license, intended use,
labeling method, limitations, split policy, version, and cryptographic hashes.

The [Bitext retail/e-commerce review set](./bitext-retail-ecommerce-v1/CARD.md) is the first
external-source challenge set. It needs independent route review before it may be scored;
its source intents are not benchmark labels.
