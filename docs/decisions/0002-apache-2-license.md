# ADR-0002: Apache License 2.0

- Status: Accepted
- Date: 2026-09-22

## Context

The project is intended for broad use in commercial and open-source agent systems. Contributors
and adopters benefit from explicit patent terms in addition to permissive copyright terms.

## Decision

License original project code under Apache License 2.0. Dataset and third-party fixture licenses
must be documented independently; inclusion in this repository does not relicense them.

## Consequences

Users receive a permissive license with an express patent grant. Distributions must preserve the
license and applicable notices. Contributions are accepted under the same license unless stated
otherwise.

## Alternatives

MIT was considered for brevity but does not contain an express patent grant. Dual licensing is
unnecessary for the initial project.
